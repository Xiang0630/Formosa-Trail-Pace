# Formosa Trail EPh 配速計算器

非官方的 Formosa Trail 54K / 40K 配速規劃網站。

## 發布進度
此提交僅建立組別選擇首頁；ft54.html 與 ft40.html 尚待後續提交。請在兩份計算器上傳完成後再啟用 GitHub Pages。

## 預定檔案
- index.html：響應式組別選擇首頁。
- ft54.html：以使用者提供的 FT54 Pace-0.4 為基礎，新增組別導覽。
- ft40.html：以使用者提供的 FT40 Pace-0.1 為基礎，新增組別導覽。
- .nojekyll：靜態網站標記。

## 資料聲明
首頁距離、爬升與預設起跑時間沿用使用者提供的 HTML，未重新驗證官方賽事公告。路線與關門時間請以主辦單位最新公告為準。

## 隱私
新增首頁不使用第三方追蹤、外部字型或外部腳本，也不自動上傳配速設定。
